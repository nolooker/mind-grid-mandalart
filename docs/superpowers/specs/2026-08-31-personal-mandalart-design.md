# 개인용 만다라트 앱 설계

## 목적

여러 개의 만다라트를 만들고 목표를 구조화하며, 실행 항목의 완료 여부와 진행률을 한눈에 관리하는 개인용 웹 앱을 만든다. 계정이나 서버 없이 현재 브라우저에 자동 저장되어 바로 사용할 수 있어야 한다.

## 제품 범위

첫 버전은 다음 기능을 제공한다.

- 여러 만다라트 생성, 전환, 이름 변경, 복제, 삭제
- 하나의 중심 목표, 8개의 핵심 목표, 핵심 목표별 8개의 실행 항목 편집
- 9×9 전체 보드와 선택 영역의 3×3 확대 편집기
- 실행 항목 완료 체크
- 핵심 목표별 진행률과 전체 진행률
- 브라우저 자동 저장 및 새로고침 후 복원
- 전체 데이터의 JSON 내보내기 및 가져오기
- 첫 사용자를 위한 예시 만다라트와 빈 상태 안내
- 데스크톱과 모바일에 대응하는 반응형 화면
- 키보드 조작과 접근성 레이블

계정, 서버 저장, 여러 기기 동기화, 협업 기능은 첫 버전에서 제외한다.

## 화면 구조

### 앱 셸

데스크톱에서는 왼쪽 사이드바와 오른쪽 작업 영역으로 구성한다. 사이드바에는 앱 이름, 만다라트 목록, 새 만다라트 버튼, 백업 메뉴를 배치한다. 작업 영역에는 선택한 만다라트의 제목과 전체 진행률, 9×9 전체 보드, 선택한 3×3 영역의 확대 편집기를 배치한다.

모바일에서는 사이드바를 상단의 만다라트 전환 메뉴로 바꾸고, 전체 보드 아래에 확대 편집기를 세로로 배치한다. 전체 보드는 구조 파악용으로 유지하며 실제 문구 편집은 충분히 큰 확대 편집기에서 수행한다.

### 전체 보드

전체 보드는 만다라트의 관계를 시각화한다. 중앙 칸은 최종 목표, 중앙 주변 8칸은 핵심 목표, 바깥 8개 3×3 영역은 각 핵심 목표와 그에 속한 실행 항목을 보여준다. 각 핵심 목표에는 일관된 포인트 색상을 지정해 관계를 구분한다.

전체 보드의 칸이나 영역을 선택하면 연결된 3×3 영역이 확대 편집기에 열린다. 선택 상태는 색상과 테두리를 함께 사용해 표시한다.

### 확대 편집기

중앙 영역을 선택한 경우 최종 목표와 8개의 핵심 목표를 편집한다. 바깥 영역을 선택한 경우 해당 핵심 목표와 8개의 실행 항목을 편집한다. 실행 항목에는 완료 체크 컨트롤을 제공한다. 텍스트 변경과 체크 변경은 즉시 화면에 반영한다.

### 관리 기능

새 만다라트는 이름을 입력해 생성한다. 이름 변경과 복제는 목록의 항목 메뉴에서 수행한다. 삭제는 확인 단계를 거친다. 마지막 만다라트를 삭제한 경우 빈 상태를 보여주고 새 만다라트 생성 동작을 안내한다.

## 시각 방향

차분한 아이보리 계열 배경과 또렷한 텍스트를 기본으로 한다. 8개 핵심 목표에는 서로 구분되지만 과도하게 채도가 높지 않은 포인트 색상을 사용한다. 둥근 카드, 절제된 그림자, 충분한 여백으로 81칸의 정보 밀도를 완화한다. 장식용 이미지 없이 타이포그래피, 색상, 격자 구조로 제품의 성격을 드러낸다.

## 데이터 모델

앱 상태는 다음 정보를 포함한다.

- 스키마 버전
- 현재 선택된 만다라트 ID
- 만다라트 배열
- 각 만다라트의 ID, 제목, 중심 목표, 생성 시각, 수정 시각
- 8개 핵심 목표의 ID, 제목, 색상 키
- 핵심 목표별 8개 실행 항목의 ID, 문구, 완료 상태

ID는 복제와 편집 과정에서도 안정적으로 항목을 식별할 수 있도록 생성 시 부여한다. 저장 데이터에는 스키마 버전을 포함해 향후 형식 변경 시 마이그레이션할 수 있게 한다.

## 저장과 백업

상태 변경은 즉시 UI에 반영하고 짧은 디바운스 후 하나의 버전 관리된 JSON 값으로 `localStorage`에 저장한다. 앱 시작 시 저장값을 검증해 복원한다. 저장값을 읽을 수 없거나 필수 구조가 손상된 경우 해당 값을 덮어쓰지 않고 안전한 초기 상태로 앱을 연다.

내보내기는 현재 저장된 모든 만다라트를 버전 정보와 함께 JSON 파일로 내려받는다. 가져오기는 파일 형식과 구조를 검증한 뒤, 기존 데이터를 대체할 것인지 명확히 확인하고 적용한다. 잘못된 파일은 상태를 변경하지 않고 이해하기 쉬운 오류를 표시한다.

`localStorage`는 같은 브라우저와 기기에서만 유지된다. 브라우저 데이터 삭제나 기기 변경에 대비한 수단은 JSON 백업이다.

## 진행률 규칙

완료 상태는 실행 항목에만 적용한다. 핵심 목표별 진행률은 문구가 작성된 실행 항목 중 완료된 항목의 비율이다. 전체 진행률은 전체 만다라트에서 문구가 작성된 실행 항목 중 완료된 항목의 비율이다. 작성된 실행 항목이 하나도 없으면 진행률은 0%로 표시한다.

문구가 없는 실행 항목은 분모에서 제외한다. 완료된 실행 항목의 문구를 모두 지우면 해당 항목의 완료 상태도 해제해 보이지 않는 완료 데이터가 남지 않도록 한다.

## 상호작용과 접근성

모든 편집 및 관리 동작은 키보드로 접근할 수 있어야 한다. 아이콘만 사용하는 컨트롤에는 접근성 이름을 제공한다. 포커스 상태를 명확히 표시하고, 색상만으로 선택이나 완료 상태를 전달하지 않는다. 삭제, 가져오기처럼 기존 데이터에 영향을 주는 동작은 확인 단계와 명확한 결과 메시지를 제공한다.

## 오류 처리

- 저장 공간 부족이나 브라우저 저장 실패 시 편집 내용은 현재 화면에 유지하고 저장 실패 안내를 표시한다.
- 손상된 저장 데이터는 앱 실행을 막지 않는다.
- 잘못된 백업 파일은 기존 데이터를 변경하지 않는다.
- 마지막 선택 항목이 삭제되거나 존재하지 않으면 남아 있는 첫 번째 만다라트로 안전하게 전환한다.
- 이름이나 목표 문구는 공백만 입력된 값을 정리해 빈 값으로 처리한다.

## 검증 기준

- 만다라트를 생성, 전환, 이름 변경, 복제, 삭제할 수 있다.
- 중심 목표, 핵심 목표, 실행 항목을 편집하면 전체 보드와 확대 편집기에 일관되게 반영된다.
- 새로고침 후 모든 만다라트와 선택 상태가 복원된다.
- 실행 항목 체크와 문구 변경에 따라 핵심 및 전체 진행률이 정확히 계산된다.
- JSON으로 내보낸 데이터를 다시 가져오면 동일한 상태가 복원된다.
- 잘못된 저장값이나 가져오기 파일로 인해 앱이 중단되거나 기존 데이터가 손상되지 않는다.
- 데스크톱과 모바일에서 전체 구조를 확인하고 편집할 수 있다.
- 주요 기능을 키보드로 사용할 수 있고 포커스 상태와 접근성 이름이 제공된다.

## 구현 경계

한 페이지 안에서 앱 셸, 보드, 확대 편집기, 관리 메뉴를 구성한다. 영속 상태와 진행률 계산은 UI 표현과 분리해 검증 가능하게 유지한다. 외부 API, 데이터베이스, 로그인, 분석 도구는 사용하지 않는다.
