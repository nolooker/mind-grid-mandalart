# 개인용 만다라트 앱 설계

## 목적

마인드그리드는 개인이 큰 목표를 구조화하고, 실행 가능한 행동으로 내려보며, 완료 상태와 진행률을 관리하는 개인용 만다라트 앱이다. 사용자는 여러 개의 만다라트를 만들 수 있고, 각 만다라트는 한 단계 더 깊은 상세 9×9 구조를 가진다.

## 제품 방향

앱의 핵심 방향은 “큰 지도 → 상세 지도 → 오늘 할 행동”이다. 전체 9×9는 삶이나 프로젝트의 큰 방향을 보여주고, 각 큰 방향 안에는 다시 9×9 상세 만다라트를 둔다. 단, 무한 depth로 확장하지 않고 한 번만 더 깊게 들어간다. 이렇게 하면 목표를 충분히 세분화하면서도 탐색 복잡도를 관리할 수 있다.

## 기능 범위

- 관리 비밀번호를 입력해야 앱을 열 수 있다.
- 여러 만다라트를 생성, 전환, 이름 변경, 복제, 삭제할 수 있다.
- 각 만다라트는 중심 목표와 8개의 큰 방향을 가진다.
- 각 큰 방향은 자체 상세 9×9 만다라트를 가진다.
- 상세 9×9의 가운데 칸은 세부 방향 목록/설계 편집으로 연결된다.
- 상세 9×9의 바깥 8개 방향은 각 방향의 행동 편집으로 바로 연결된다.
- 실행 행동은 문구 입력과 완료 체크를 지원한다.
- 전체 진행률, 큰 방향 진행률, 세부 방향 진행률을 표시한다.
- JSON 백업 내보내기/가져오기를 제공한다.
- 데스크톱과 모바일에 대응한다.

협업, 사용자별 계정 로그인, 공유 권한 관리, 무한 depth 구조는 현재 범위에서 제외한다.

## 화면 구조

### 앱 셸

데스크톱에서는 왼쪽 사이드바와 오른쪽 작업 영역으로 구성한다. 사이드바에는 앱 이름, 만다라트 목록, 새 만다라트 버튼, 백업 컨트롤, 저장 상태를 배치한다. 작업 영역에는 선택한 만다라트 제목, 전체 진행률, 편집 패널, 9×9 보드를 배치한다.

모바일에서는 편집 패널을 9×9 보드보다 먼저 보여준다. 핸드폰에서는 전체판을 정교하게 조작하기보다 큰 방향 목록과 행동 편집을 자주 사용하므로, 편집 흐름을 우선 배치하고 9×9 보드는 확인용으로 아래에 둔다.

### 전체 9×9

전체 9×9는 선택한 만다라트의 가장 상위 지도다.

- 가운데 칸: 만다라트의 중심 목표
- 가운데 주변 8칸: 큰 방향
- 바깥 8개 3×3 영역: 큰 방향과 대표 행동/상태 미리보기

전체판에서 큰 방향을 클릭하면 해당 큰 방향의 상세 9×9로 진입한다.

### 상세 9×9

상세 9×9는 하나의 큰 방향을 다시 세분화한 지도다.

- 가운데 칸: 현재 큰 방향의 중심 목표
- 가운데 주변 8칸: 세부 방향
- 바깥 8개 3×3 영역: 각 세부 방향과 그 방향의 실행 행동

상세판의 클릭 규칙은 다음과 같다.

- 가운데 칸 클릭: 세부 방향 목록/설계 편집
- 바깥 8개 방향 클릭: 해당 세부 방향의 행동 편집
- 뒤로가기: 행동 편집에서 상세판으로, 상세판에서 전체판으로 이동

## 데이터 모델

앱 상태는 하나의 버전 관리 JSON 구조로 저장한다.

- `schemaVersion`
- 현재 선택된 만다라트 ID
- 만다라트 배열
- 각 만다라트의 ID, 제목, 중심 목표, 생성/수정 시각
- 각 만다라트의 8개 큰 방향
- 각 큰 방향의 ID, 제목, 색상 키, 기존 호환용 행동 배열
- 각 큰 방향의 8개 세부 방향
- 각 세부 방향의 ID, 제목, 색상 키
- 각 세부 방향의 8개 실행 행동

기존 저장 데이터에 `detailGoals`가 없는 경우, 불러올 때 자동으로 상세 9×9 구조를 보강한다. 예전 큰 방향 아래에 있던 행동은 첫 번째 세부 방향으로 옮겨 이어 쓸 수 있게 한다.

## 저장과 보안

데이터는 OpenAI Sites에 연결된 D1 SQLite DB에 저장한다. D1에는 개인 workspace의 전체 만다라트 상태를 하나의 JSON 값으로 보관한다. 같은 URL과 같은 관리 비밀번호로 접속하면 기기가 달라도 같은 데이터를 볼 수 있다.

관리 비밀번호는 Sites 런타임 환경변수 `MANDALART_PASSCODE`에 저장한다. 클라이언트는 API 요청 시 비밀번호를 헤더로 보내고, 서버는 저장된 환경변수와 비교해 읽기/쓰기 요청을 허용한다. 이 방식은 개인용 잠금 장치로 적합하지만, 다중 사용자 계정 시스템이나 세밀한 권한 관리를 대체하지는 않는다.

## 진행률 규칙

완료 상태는 실행 행동에만 적용한다.

- 세부 방향 진행률: 해당 세부 방향에서 문구가 작성된 행동 중 완료된 행동의 비율
- 큰 방향 진행률: 큰 방향의 8개 세부 방향 안에 작성된 행동 전체 중 완료된 행동의 비율
- 전체 진행률: 만다라트 전체의 모든 세부 행동 중 완료된 행동의 비율

문구가 없는 행동은 분모에서 제외한다. 완료된 행동의 문구를 지우면 완료 상태도 해제해 보이지 않는 완료 데이터가 남지 않도록 한다.

## 시각 방향

차분한 아이보리 배경과 짙은 녹색 계열의 중심 색을 사용한다. 8개 방향은 서로 구분되는 낮은 채도의 포인트 컬러를 사용한다. 81칸 구조의 정보 밀도를 완화하기 위해 둥근 카드, 절제된 그림자, 넉넉한 터치 영역을 유지한다.

## 접근성

아이콘만 있는 버튼에는 접근성 이름을 제공한다. 키보드 포커스 상태를 명확히 표시하고, 색상만으로 선택/완료 상태를 전달하지 않는다. 모바일에서는 입력 필드와 체크박스의 터치 영역을 충분히 크게 유지한다.

## 검증 기준

- 관리 비밀번호 입력 후 앱을 열 수 있다.
- 여러 만다라트를 만들고 관리할 수 있다.
- 전체 9×9에서 큰 방향을 눌러 상세 9×9로 들어갈 수 있다.
- 상세 9×9의 가운데 칸은 세부 방향 목록/설계 편집으로 연결된다.
- 상세 9×9의 바깥 방향은 해당 행동 편집으로 바로 연결된다.
- 행동 문구와 완료 체크가 저장되고 진행률에 반영된다.
- 기존 저장 데이터도 상세 9×9 구조로 안전하게 보강된다.
- JSON 백업을 내보내고 다시 가져올 수 있다.
- 모바일에서 편집 영역이 먼저 보여 실제 사용 흐름이 편하다.
- 테스트와 프로덕션 빌드가 통과해야 배포한다.

## 구현 경계

마인드그리드는 현재 개인용 앱이다. 데이터는 하나의 D1 상태 레코드로 관리하고, API는 관리 비밀번호로 보호한다. 향후 진짜 로그인, 사용자별 데이터 분리, 공유 기능이 필요해지면 데이터 모델과 인증 구조를 별도 단계로 확장한다.
